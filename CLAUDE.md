# CampusNav

## Project
CampusNav is an Indoor Campus Navigation System for Kalsekar Technical Campus.

It helps students, faculty and visitors find classrooms, labs, offices and other campus facilities.

Departments:
- Engineering
- Pharmacy
- Architecture

## Tech Stack
- Frontend: Next.js, React, TypeScript/JavaScript, Tailwind CSS
- Backend: Python, FastAPI
- Database: PostgreSQL via Supabase
- Navigation: Dijkstra's Algorithm
- DevOps: GitHub Actions, Docker, Docker Hub

## Important Rules
- Preserve existing navigation logic and map data unless explicitly asked.
- Do not change node IDs or connections unnecessarily.
- Keep UI mobile responsive and consistent with CampusNav.
- Avoid modifying unrelated files.
- Use environment variables for secrets.
- Run `npm run build` after significant frontend changes.
- Do not commit or push unless explicitly requested.
