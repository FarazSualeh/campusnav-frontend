# CampusNav

Indoor navigation for Anjuman-i-Islam's Kalsekar Technical Campus.

## Run locally

```bash
npm install
npm run dev
```

Open <http://localhost:3000>.

## Routes

- `/` - landing page
- `/about` - project and creators
- `/map` - interactive campus maps

## Commands

```bash
npm run lint    # Check code
npm run build   # Create production build
npm start       # Start production server
```
